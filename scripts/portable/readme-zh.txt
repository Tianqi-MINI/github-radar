GitHub 兴趣雷达 - Windows 便携版
================================

一、怎么使用

1. 先把整个压缩包完整解压到一个文件夹。
   不要在压缩软件预览窗口里直接双击运行。
2. 双击 start-github-radar.bat。
3. 稍等几秒，浏览器会自动打开页面。
4. 如果浏览器没有自动打开，复制黑色窗口里显示的地址，
   粘贴到浏览器地址栏。
5. 使用期间不要关闭黑色窗口。
6. 用完以后，直接关闭黑色窗口即可停止服务。

二、电脑要求

- Windows 10 或 Windows 11，64 位。
- 不需要安装 Python。
- 不需要管理员权限。
- 实时搜索需要联网；断网时会自动使用本地精选项目。

三、常见问题

1. Windows 提示“已保护你的电脑”
   这是下载文件常见的系统提示。确认文件来源可信后，
   可以右键压缩包，打开“属性”，勾选“解除锁定”，再解压。

2. 双击后没有出现页面
   先确认黑色窗口没有关闭，再看窗口里显示的地址。
   如果提示端口被占用，启动器会自动尝试下一个端口。

3. 页面打不开或搜索失败
   先检查网络；断网时本地精选仍可用。
   如果仍失败，把黑色窗口里的错误信息截图发给维护者。

4. 会不会把我的资料上传？
   不会。问卷、设置和推荐历史只保存在当前浏览器。
   页面内的 GitHub Token 功能在托管模式下会关闭。

四、隐私提醒

- 不需要填写真实姓名、身份证号、手机号或支付信息。
- 不要把 GitHub Token 发给别人，也不要放进聊天记录或截图。
- 本项目只读取 GitHub 的公开仓库信息。
