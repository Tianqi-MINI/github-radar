## 关键经验

1. **首屏不能依赖外网。** v3 把推荐和 README 改为本地缓存，是可用性最重要的一次提升。
2. **问卷必须真的影响结果。** v6 之前只是「收集」，v6 之后才把配置映射到分数、排序和理由。
3. **推荐系统需要显式多样性约束。** v15 的「每主题最多 2 条」比单纯调权重更有效。
4. **失败要有可解释的降级。** v18 的「自动回退 + 标注原因」比静默失败体验好得多。
5. **信息密度要分层。** v20 把卡片压到 4 行，是信息架构的一次纠偏。
6. **自由输入需要本地语义解析。** v21 用 `FOCUS_INTENTS / MAJOR_INTENTS / RESEARCH_STAGE_RULES`
   把自然语言映射到结构化标签，避免继续堆固定选项。
7. **引导只讲下一步行动。** v22 每步只指向一个真实界面区域，并允许跳过和重复打开；
   完成状态保存在本地，避免每次刷新都造成打扰。

## 便携包补充（2026-11-22）

- 新增 Windows 便携包打包脚本，内置官方 Python 3.12.10 嵌入式运行时。
- 用户免安装 Python、免管理员权限；双击启动器即可使用，退出时关闭窗口。
- 启动器自动选择 4173-4190 的空闲端口，等待健康检查通过后打开浏览器。
- 打包脚本强制排除 Git 数据、SSH 密钥、Token 文件、本地覆盖配置、缓存和日志。
- 输出 ZIP 与 SHA256 校验文件，保留版本目录以便追溯；输出目录不进入 Git。
- 校验后的版本化副本进入 `downloads/`；推送 `v*` 标签后由 GitHub Actions 重新
  校验并发布为固定名称的 Release 附件。
