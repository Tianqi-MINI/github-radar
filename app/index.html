      连接后额度提升到每小时 5,000 次，抓取更稳。Token 只保存在这台电脑的本地项目目录里， 不会写进网页代码，也不会从服务器回传给浏览器。

      创建一个只读 Token

      推荐使用 Classic Personal Access Token。这个项目只读取公开 GitHub 信息， 不需要仓库写入、Actions、组织管理或管理员权限。

      Token 创建网址 https://github.com/settings/tokens/new?description=Interest%20Radar&scopes=
      1. 打开上方 Token 创建网址，并确认当前登录的是你自己的 GitHub 账号。
      2. 在 Note 或名称中填写 Interest Radar，方便以后识别和撤销。
      3. Expiration 选择 30 天、60 天或 90 天。建议先用较短有效期， 到期后重新生成。
      4. Scopes 保持全部不勾选。公开仓库只读请求不需要额外权限； 不要授予 repo、workflow 或组织管理权限。
      5. 点击 Generate token。Token 只显示一次，复制完整的 ghp_ 或 github_pat_ 字符串。
      6. 粘贴到下方输入框，点击“保存并验证”。成功后会显示 GitHub 用户名， 额度提升到每小时 5,000 次。

      不要把这个 Token 粘贴到聊天、Issue、README 或代码仓库。若提示 Token 无效或已过期，请回到 GitHub 撤销旧 Token 后重新生成。
